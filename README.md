## 👋 Sobre mim

> **Construo sistemas que resolvem problemas reais de negócio** — do banco de dados à interface, do servidor ao pipeline de entrega.

Sou Fullstack Engineer com foco em **APIs escaláveis**, **plataformas cloud-native** e **automação de infraestrutura**. Atuo no mercado **fintech** combinando desenvolvimento de produto com práticas modernas de DevOps e AppSec.

- 🏗️ Arquiteto soluções end-to-end com TypeScript, Go, PHP e AWS
- ☁️ Infraestrutura como Código com Terraform no Azure e AWS
- 🔐 Visão de AppSec integrada ao ciclo de desenvolvimento
- 🚀 Entrega contínua com pipelines CI/CD automatizados
